# 微信读书 · 电脑端下载助手 —— 视觉设计说明

本文记录图形版（`desktop_app.py`）重设计的设计决策。

> 2026-10-21：网页版已从仓库删除（脚本语法错误导致整页无响应，且长期无维护价值），
> 因此下文的「迁移到网页版」一节仅作为历史留存，不再有对应实现。

改造前后的功能、文案语义与行为**完全不变**，只改视觉与信息架构的呈现方式。

## 1. 设计定位

**暖调编辑风（warm editorial）**：把工具做成一份可以静读的排版稿，而不是蓝色 SaaS 后台。

三条原则：

1. **颜色只花在该表达含义的地方。** 界面没有装饰性色块。唯一的强调色是陶土／赤陶
   （clay/terracotta），绝不使用默认主题蓝。
2. **用 1px 发丝线分隔，而不是厚重的卡片堆叠。** 所有表面色都偏暖且彼此接近
   （`#F4F2EE` / `#FFFFFF` / `#FAF8F4`），靠极小的明度差和发丝线建立层次。
3. **纯黑被刻意回避。** 主文字是暖调近黑 `#2B2825`，与纸色背景同源。

## 2. 字体

| 角色 | 字体 | 用途 |
| --- | --- | --- |
| 展示体 | `Noto Serif SC` | 应用标题、书籍标题、分节标题 |
| 功能体 | `Microsoft YaHei UI` | 正文、标签、按钮 |
| 等宽体 | `Cascadia Mono` | 日志面板、ID、验证码 |

字体是编辑感的主要来源：**中文衬线做展示体，OS 无衬线做功能体**，两者分工明确。
本机已装 `Noto Serif SC`，因此无需把字体打进 48 MB 的安装包。

所有字体经 `_font(size, weight, family)` 单一入口创建，保证字号阶梯一致。

### 字号阶梯

| 尺寸 | 字重 | 字体 | 位置 |
| --- | --- | --- | --- |
| 22 | bold | SERIF | 应用主标题、登录框标题 |
| 14 | bold | SERIF | 书籍标题 |
| 13 | normal | SANS / MONO | 正文、输入框、按钮 |
| 12 | normal | SANS | 标签、状态、次要说明 |
| 11 | normal | MONO | 日志面板 |

## 3. 色彩令牌

定义在 `DesktopApp` 类体内，全部为类常量，禁止在别处硬编码色值。

### 表面

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `BG` | `#F4F2EE` | 暖骨色画布 |
| `CARD` | `#FFFFFF` | 主表面 |
| `SUNKEN` | `#FAF8F4` | 嵌套表面：导出面板、简介、日志 |
| `HAIRLINE` | `#E4E0D8` | 1px 结构分隔线 |
| `HAIRLINE_SOFT` | `#EEEBE4` | 更弱的内部分隔线 |

### 文字

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `INK` | `#2B2825` | 主文字，暖调近黑 |
| `MUTED` | `#6E675E` | 次要文字 |
| `FAINT` | `#9B948A` | 元信息／三级文字、未评分 |

### 唯一强调色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `ACCENT` | `#8A4A2E` | 主操作按钮、搜索按钮、选中态、进度条 |

| `ACCENT_TINT` | `#F2E8E1` | 卡片悬停底色 |

### 语义色（全部去饱和）

| 令牌 | 值 | 配对浅底 |
| --- | --- | --- |
| `GREEN` | `#3C6B41` | `GREEN_TINT` `#EDF3EC` |
| `RED` | `#9F2F2D` | `RED_TINT` `#FBEAEA` |
| `AMBER` | `#8A5B12` | `AMBER_TINT` `#FAF1DC` |

评分标签按**有无评分**取色：有评分用 `AMBER`，无评分用 `FAINT`，避免把「暂无信息」
渲染成警告色。

## 5. 信息架构

信息架构被允许重排，改造后的阅读顺序是「先找书、再确认、后下载」：

```
报头（衬线主标题 + 副题）        ← 编辑式刊头
─────────────────────────────  发丝线
I  搜索书籍        │  II  确认书籍
   输入 + 搜索     │     封面 + 书名 / 作者 / 分类 / 评分 / ID
   结果计数        │  ─────────────────────  发丝线
   书籍卡片列表    │     简介
   （可滚动）      │  ─────────────────────
                  │  III 下载到电脑
                  │     并发 + 起止章节
                  │     先检查第一章 / 开始下载
                  │  ─────────────────────
                  │     进度条
                  │     状态文案
                  │     暂停下载 / 查看技术日志 / 打开下载目录
                  │     日志最近一行（peek）
```

要点：

- **罗马数字 `I / II / III`** 作为分节标记，替代默认的方框＋粗标题，比色块更轻。
- 左列可滚动，右列固定为「确认 + 下载」操作区，两者用 0.36 / 0.64 权重分配。
- 日志面板只保留 32px 高作为**最近一行的 peek**；完整日志通过「查看技术日志」按钮打开
  真实文件。这是刻意的信息降级，不是被挤扁的妥协。

## 6. 控件约定

- **主操作**（搜索、开始下载、保存并使用、提交验证码）用 `ACCENT` 实心。
- **次操作**（关闭、重新获取、查看技术日志、打开下载目录）用 `_quiet_button()`：
  白底 + 发丝线 + `ACCENT_ON_TINT` 文字。
- **登录页签**用圆形单选指示器，选中环为 `ACCENT`，避免引入第二个强调色。
- 卡片悬停：底色转 `ACCENT_TINT`，边框转 `ACCENT`。

## 7. CustomTkinter 踩坑记录

这一节的每一条都是实际卡住过的，重做时不要重蹈。

1. **同一父容器里不能混用 `pack` 和 `grid`。** 导出面板内部用 `grid`，
   它的父级就必须一路 `pack` 上来。
2. **`CTkLabel` 不支持 `border_width` / `border_color`。** 需要描边时，把标签放在一个
   发丝线 `CTkFrame` 上（二维码卡、输入框卡片都是这么做的）。
3. **固定高度窗口里 `pack` 会挤压靠后的子控件到 0 高**（`winfo_height() == 1`）。
   调试手段：逐个打印 `winfo_rooty()` / `winfo_height()`，用「客户区高度 − 内容底边」
   判断还差多少像素。本轮右栏共需回收约 130px。
4. **`CTkTextbox` 5.2.2 只暴露 `activate_scrollbars`**，没有独立的横／纵滚动条开关，
   但它每 200ms 自查并在 `xview() == (0.0, 1.0)` 时自动隐藏横滚条。
   换行文本在实测中不会误显示横滚条。
5. **窗口几何单位是逻辑像素，截图是物理像素。** 本机 125% DPI，`620x620` 逻辑 →
   `775x775` 像素。布局判断必须用 `winfo_height()`，不能用截图像素。

## 9. 迁移到网页版时的对应关系（**已作废**：网页版已删除）

| 图形版 | 网页版对应 |
| --- | --- |
| 类常量色板 | CSS 自定义属性（`:root` 里的 `--ink` / `--accent` 等） |
| `_font()` | `font-family` 三段分工，衬线只给展示体 |
| `HAIRLINE` 1px 分隔 | `border-bottom: 1px solid` |
| 罗马数字分节 | 分节标题里的小号衬线数字 |
| 日志 peek | 页面底部的单行状态条 |

网页版不需要遵守 CustomTkinter 的第 7 节那些坑，但**色板、字体分工、控件轻重层级**
必须保持一致，否则两端会看起来像两个产品。
