# WeReadDownloader

把微信读书里的书导出成 EPUB，**划线一条不丢**，可断点续传，也能导入 Kindle 上的 KOReader。

![下载工坊](docs/screenshots/01-workflow.png)

> **仅供个人备份使用。** 请只导出你账号里自己有权访问的内容。

---

## 下载安装

从 [Releases](../../releases) 下载 `WeReadDownloader-Setup.exe`，双击安装。

安装向导只有一个选项：装到 `C:\Program Files\WeReadDesktop`，并在桌面放一个名为
**WeReadDownloader** 的快捷方式。

---

## 怎么用

界面分三步，从左到右、从上到下依次完成：

![下载工坊](docs/screenshots/01-workflow.png)

**① 搜索** —— 顶栏输入书名或作者，点「搜索」，结果出现在左侧「① 搜索结果」。

**② 确认** —— 点搜索结果里任意一本，右侧「② 确认书籍」会显示封面、分类和简介。
这一步是在确认程序拿到了这本书的正确版本，避免下错书。

**③ 下载** —— 点「先检查第一章」。这一步会真的去取第一章正文并验证协议是否可用，
**几十秒后就退出，不会开始下载整本书**。确认没问题再点「开始下载 / 继续下载」。

> 中途关掉或断网都不要紧。重新下载同一本书会从上次停下的章节继续，不会从头再来。

### 我的书架：直接从账号里挑书

不用搜书也可以 —— 「我的书架」页直接列出你微信账号里的真实书籍，点书名或「下载」即可。
上半部分是微信书架（你正在读的书），下半部分是「本机已导出」（已经导到电脑上的书，
可以打开、删想法、删除、清理半成品）。

![我的书架](docs/screenshots/02-bookshelf.png)

> 截图里的书名和封面已遮挡 —— 那是账号的真实书架，属于个人阅读记录，不该出现在公开仓库里。

### 「含想法」开关：关掉不会少划线

这是最容易误解的一个开关。它的名字容易让人以为「关掉 = 划线也没了」，**不是**。

**划线（高亮）永远完整保留**，跟这个开关无关。开关只决定「想法」相关的两类东西要不要写进成品：

| 关掉之后 | 划线（高亮） | 想法正文（你写的笔记） | 想法元数据（作者资料、想法时间等） | 划线落点数据 |
|---|---|---|---|---|
| | ✅ **一条不少** | ❌ 不写入 | ❌ 不写入 | ✅ 必须保留 |
| 开关开着时 | ✅ | ✅ | ✅ | ✅ |

**为什么关掉还能保住划线**：微信读书的划线本身不单独存，它挂在「想法」下面，
定位靠的是想法里的**选中文字摘要**（代码里的 `abstract`）。程序拉取时无论如何都要拿到
这份落点数据，否则一条划线都放不回去。所以关掉开关省下来的**只是体积**，不是划线。

省多少：《超神机械师》全书 1483 章，关掉后 `reviews.jsonl` 从 **772 MB 降到 156 MB**。
体积大头其实是每条想法附带的作者资料、书籍记录、话题、关注状态和时间戳 —— 这些占
JSON 的九成以上，而它们对划线落点毫无用处。

**建议**：只想要书和划线 → 关掉。自己写的笔记想留着 → 开着。

## 下载结果在哪

```
%LOCALAPPDATA%\WeReadDesktop\exports\
└── 书名-书籍ID\
    ├── 书名 - full.epub           # 可直接阅读，含划线
    ├── 书名 - full.weread.zip     # 导入 KOReader 用的包（见下）
    ├── manifest.json              # 章节清单 + 本书缺了什么
    └── reviews.jsonl              # 划线落点与想法（关掉开关则没有）
```

`manifest.json` 里的 `omissions` 会**明说这本书少了什么**（比如某章图片没取到）。
程序宁可降级也不失败，所以偶尔会有缺图缺章 —— 清单里写着，不会让你以为书是完整的。

**日志位置**：`%LOCALAPPDATA%\WeReadDesktop\logs\`（反馈问题请连同这个目录一起提供）

## 导入 Kindle

导出的 `书名 - full.weread.zip` 就是给 KOReader 用的。**Kindle 原生系统不支持它**，
必须配合 KOReader 使用。

### 怎么导

1. 把 `.weread.zip` 通过各种方式弄到 KOReader 能读到的位置（数据线拷贝、网盘同步、
   或用 KOReader 联网传书功能）
2. KOReader 里进 **WeRead → Import desktop WeRead bundle**
3. 选中刚拷进去的那个 `.weread.zip`

导入全程**不访问网络**。

### 原理是什么

普通的 EPUB 划线是存在书里的标注层，但微信读书的划线有两个额外的东西，EPUB 格式
装不下：

- 划线对应的是**想法**，一条划线可能带一段你自己写的笔记
- 划线在原文里的**精确落点**是一段字符区间（`range`），不是页码也不是段落号

所以程序把 EPUB 和划线数据**分开装**：`.weread.zip` 里面是

| 文件 | 作用 |
|---|---|
| `书名 - full.epub` | 正文，划线锚点已经打进去 |
| `reviews.jsonl` | 每条划线的区间、选中文字、笔记正文 |
| `manifest.json` | 章节清单、缺失说明 |
| `bundle.json` | 索引，告诉导入器上面三个文件叫什么 |

`bundle.json` 就是索引，导入器读它就知道该取哪些文件。KOReader 拿到书之后，
把 `reviews.jsonl` 里的划线按区间重新贴回去，点开划线还能看到你当时写的笔记。

**一句话**：正文靠 EPUB，划线靠旁边的 json，导入器负责把两者对齐。

## 登录

首次使用点右上角账号按钮：

- **扫码**（默认）—— 微信扫一扫，按提示操作
- **手动输入** —— 填 API Key 和 `wr_skey`，从
  [weread.qq.com/r/weread-skills](https://weread.qq.com/r/weread-skills) 复制

凭证用 Windows DPAPI 加密后存在本机，**不进日志、不进安装包、不进仓库**。
仓库里有一条 pre-push 钩子，每次推送前自动扫描硬编码密钥和凭证文件。

## 已知限制

- 同一时间只能跑一个下载任务
- 想法数据即便关掉开关也仍会从服务器拉取（划线落点依赖它），只是不写入成品
- 退出登录只删扫码会话，`weread-live-settings.lua` 里的基础凭证需手动删除
