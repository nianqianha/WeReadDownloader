# WeReadDownloader

把微信读书里的书导出成 EPUB：正文完整，划线和注释按你选的方式收进书末附录，支持断点续传和排队下载。Windows 桌面程序。

![下载工坊](docs/screenshots/01-workflow.png)

## 下载安装

从 [Releases](../../releases) 下载 `WeReadDownloader-Setup.exe`，双击安装。

安装包只问装到哪、要不要桌面快捷方式。主程序和下载组件一起安装，没有可选的组件。

## 界面

左侧五个页面：

| 页面 | 用途 |
|---|---|
| 下载工坊 | 搜索、确认书籍、开始下载；排队下载 |
| 我的书架 | 账号里的书直接下载；本机已导出的书可以打开、删除 |
| 下载记录 | 每本书的下载结果 |
| 存储占用 | 导出目录占了多少、哪些可以回收 |
| 设置 | 下载目录、日志目录、账号、标注方式说明、检查更新 |

### 下载一本书

「下载工坊」从左到右三步：

1. **搜索**：顶栏输入书名或作者，点「搜索」。
2. **确认**：点搜索结果里的一本，右侧显示封面、分类、简介和书籍 ID，确认是你要的版本。
3. **下载**：先点「先检查第一章」验证账号和协议可用（只取一章，不会开始整本下载），再点「开始下载 / 继续下载」。

中途关掉程序或断网都没关系：再次下载同一本书会从断点续传。

### 排队下载

在搜索结果里勾选多本，点结果卡片上的「加入队列 N 本」，再点顶栏的「队列」打开队列面板，点「开始队列下载」。

- 队列按勾选顺序一本一本下载，每本结束后自动开始下一本。
- 「暂停下载」停在当前这本，书插回队首，按钮变「继续队列」。
- 下载中在结果卡片上取消勾选，轮到这本书时会跳过。
- 队列结束时如果有书没完成，会列出书名和原因；已下载的章节都保留，可以在书架里点那本书继续。

### 我的书架

「微信书架」列出账号里的书，点书名或「下载」直接开始。「本机已导出」是这台电脑上的成品：可以打开目录、删除想法数据（保留 EPUB）、删除整本，或用「全部清理」回收半成品和残留目录。

![我的书架](docs/screenshots/02-bookshelf.png)

## 标注方式

下载区右上角的「标注方式」决定成品里保留哪些内容：

| 标注方式 | 划线 | 注释 | 想法 |
|---|---|---|---|
| **注释和想法**（默认） | 有 | 书末附录 | 书末附录 |
| **注释** | 有 | 书末附录 | 无 |
| **想法** | 有 | 无 | 书末附录 |
| **纯正文** | 无 | 无 | 无 |

「注释和想法」是默认档：正文只保留角标——注是「注」字角标，想法是蓝色 `[N]`——点角标跳到书末附录。附录按约 3000 条注分册，想法单独一册，都出现在目录里，可以像普通章节一样翻。

「纯正文」连划线也不取，是四种里最快、体积最小的。

标注方式按书保存，下载中途不能切换；换挡会按新模式重新下载（已下载的章节保留在断点里，但需要重新取正文）。

## 导出结果

```
%LOCALAPPDATA%\WeReadDesktop\exports\
└── 书名-书籍ID\
    ├── 书名 - full.epub     # 成品，可直接阅读
    ├── manifest.json        # 章节清单 + 这本书缺了什么
    └── reviews.jsonl        # 划线落点与想法原始数据
```

只有 EPUB 一个成品，不生成导入包。

`manifest.json` 的 `omissions` 会写明这本书少了什么：插图没能取回多少张、有多少条划线在原文里找不到位置。程序宁可降级也不失败，所以偶尔会有缺图或缺划线——完成提示和这份清单都会说明。

单张图片超过 64 MiB 时会跳过该图并计入缺失，不会让整章失败。

**日志位置**：`%LOCALAPPDATA%\WeReadDesktop\logs\`（反馈问题请一并提供）

## 登录

分两步：

1. **拿一次 `api_key`**：浏览器打开 [weread.qq.com/r/weread-skills](https://weread.qq.com/r/weread-skills)，登录后复制页面给出的 `api_key`（形如 `wrk-...`）。
2. **程序里扫码**：点右上角账号按钮 →「扫码」，微信确认。程序会把 `api_key` 和扫码得到的会话 cookie 一起保存（cookie 用 Windows DPAPI 加密）。

| 文件 | 内容 | 有效期 |
|---|---|---|
| `weread-live-settings.lua` | `api_key` | 长期，除非在微信读书网页版注销设备 |
| `session-cookies.json` | 扫码会话（DPAPI 加密） | 会过期，重新扫码即可 |

「退出登录」会问范围：

- **仅退出会话**：只删 `session-cookies.json`，`api_key` 保留，下次打开不用重新抄。
- **彻底清除**：两个文件都删，下次需要重新扫码并重抄 `api_key`。

两个文件都在 `%LOCALAPPDATA%\WeReadDesktop\`。凭证不进日志、不进安装包、不进仓库；仓库的 pre-push 钩子会扫描硬编码密钥。

## 已知限制

- 同一时间只有一个下载任务；队列一本接一本串行执行。
- 切换标注方式会重新取章节正文（断点保留，但不会沿用旧模式的缓存）。
- 微信读书给不出某条划线在原文里的位置时，这条划线会被略去而不是标错位置；数量写在 `manifest.json` 和完成提示里。
- 微信读书服务端已删除的图片无法取回；超过 64 MiB 的单张图会被跳过。两种情况都会计入缺失说明。

## 开发

源码在 `weread/`：`desktop_app.py` 是 GUI，`weread_desktop.py` 是导出引擎，`weread_worker.py` 是两者的进程入口。打包用 `packaging/*.spec` 与 `installer/WeReadDesktop.iss`。

```
python -m pytest -q   # Python 侧测试
```

打包：先构建 `packaging/WeReadWorker.spec` 与 `packaging/WeReadDesktop.spec` 到 `release-fresh/`，再用 Inno Setup 编译 `installer/WeReadDesktop.iss`。
