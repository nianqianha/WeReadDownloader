# WeRead Downloader

把微信读书里的书导出成 EPUB，保留划线、想法和阅读进度，可断点续传，也能直接导入 Kindle 上的 KOReader。

> **仅供个人备份使用。** 请只导出你账号里自己有权访问的内容。

---

## 下载安装

从 [Releases](../../releases) 下载 `WeReadDownloader-Setup.exe`，双击安装。

安装向导可选组件：

| 选项 | 说明 |
|---|---|
| **完整安装** | 图形版 + 网页版 + 下载组件（推荐） |
| **仅图形版** | 只有桌面窗口程序 |
| **仅网页版** | 只有本地服务 + 浏览器界面（启动约 0.6 秒） |
| **桌面快捷方式** | 是否在桌面放图标 |

两个版本共用同一份下载组件，装两个界面不会让体积翻倍。

## 怎么用

### 图形版（双击「图形版（二维码登录）」）

```
① 搜索书籍        输入书名或关键词 → 点搜索
                 ↓
② 确认书籍        点左侧任意结果 → 看封面、作者、分类、简介
                 ↓
③ 下载到电脑      点「先检查第一章」确认能读 → 点「开始下载 / 继续下载」
```

**「我的书架」** 页直接列出你账号里的真实书籍，点任意一本即可开始下载。

**「含想法」开关**（默认关闭）—— 控制是否把想法（笔记正文）写入 EPUB。

> 关掉它能省下大量空间：《超神机械师》1483 章，关掉后 `reviews.jsonl` 从 772 MB 降到 156 MB，**划线一条不少**。因为划线的落点依据来自想法的摘要，所以想法数据仍会被拉取，只是不写入成品。

### 网页版（双击「网页版（0.6s 启动）」）

浏览器自动打开本地界面，功能与图形版一致。

## 下载结果在哪

```
%LOCALAPPDATA%\WeReadDesktop\exports\
└── 书名-书籍ID\
    ├── 书名 - full.epub           # 可直接阅读
    ├── 书名 - full.weread.zip     # 导入 Kindle 的包
    ├── manifest.json              # 章节 / 划线索引
    └── reviews.jsonl              # 想法数据（关掉开关则没有）
```

中途停止不会丢进度 —— 重新下载同一本书会从上次停下的地方继续。

**日志位置**：`%LOCALAPPDATA%\WeReadDesktop\logs\` （出问题时请把这个目录下的日志发给开发者）

---

## 导入 Kindle

1. 把 `书名 - full.weread.zip` 复制到 Kindle 可读存储
2. KOReader → **WeRead** → **Import desktop WeRead bundle**
3. 选择刚才的文件

导入器会校验包结构，再把 EPUB 装进下载目录、把想法写进 KOReader 的 `thoughts.db`。整个过程不访问网络。

## 登录

首次使用点「登录 / 切换账号」：

- **扫码**（默认）—— 用微信扫一扫，按提示操作
- **手动输入** —— 填 API Key 和 `wr_skey`，在 [weread.qq.com/r/weread-skills](https://weread.qq.com/r/weread-skills) 登录后复制

凭证只存在本机，不进日志、不进安装包。

## 已知限制

- 网页版与图形版**共用同一份下载组件**，同一时间只能跑一个下载任务
- 想法数据即便关掉开关也仍会从服务器拉取（划线的落点依赖它），只是不写入成品
- 退出登录只删扫码会话，`weread-live-settings.lua` 里的基础凭证需手动删除
